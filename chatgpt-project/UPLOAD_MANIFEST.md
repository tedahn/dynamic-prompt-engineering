# Upload and Setup Manifest

1. Complete `handbook/PRE_UPLOAD_SAFETY.md` locally before uploading or connecting sources.
2. Create a new ChatGPT Project and choose project-only memory when the product and account support it.
3. Paste `PROJECT_INSTRUCTIONS.md` into Project settings. Do not upload that file as a Project source.
4. Upload the approved/minimized handbook and template files listed below.
5. Run `KICKOFF_PROMPT.md` in a new Project chat.
6. Save approved outputs as separate, versioned Project sources.

Workspace type: `research`
Research subject: `modern prompt-engineering techniques as reusable Codex skills`

Before setup, assign or confirm the Project owner. If the owner remains unresolved, use the Project for research design only and do not promote or install skills.
